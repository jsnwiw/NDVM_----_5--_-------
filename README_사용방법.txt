NDVM 자연재해 취약지역 지도 — 안전동행 5개 기능 (2026-11-11)
===============================================================

[시작 방법 · Windows]
1. ZIP 압축을 풀고 폴더를 엽니다.
2. 시작하기.bat을 더블클릭합니다. (Windows에 Python이 있어야 하며 별도 pip 설치는 없습니다.)
3. 브라우저의 http://127.0.0.1:8765/#action 페이지에서 안전동행 메뉴를 이용합니다.
4. 시작할 때 열린 명령창을 닫으면 로컬 서버가 종료됩니다.
5. VS Code에서도 이 폴더에서 python -m http.server 8765 실행 후 같은 주소로 열 수 있습니다.

[안전동행 5개 기능]
01 위험요소 신고서 · 종류/장소/날짜/설명/선택 사진을 입력해 문서 미리보기, 텍스트 복사·저장, 인쇄/PDF
02 비상 연락 카드 · 비상 연락처/집결 장소 카드를 만들고 PNG 저장·인쇄
03 구호물자 매칭 · 지역/품목/수량 조건의 가상 요청·지원 목록 비교(서버 전송/실제 매칭 아님)
04 비상용품 스마트 관리함 · 이름/분류/현재 및 필요 수량/유통기한(점검일)을 등록, 수량 +/− 조정,
   부족·기한 임박/경과 물품 필터, 보충 목록 TXT 저장 및 전체 물품 CSV 내보내기
05 안심 그룹 오프라인 릴레이 · 그룹 코드와 별칭 설정, 안부 메시지/대략적 위치 기록,
   QR 코드·전달 코드·TXT 전달 파일로 수동 교환, 다른 기기에서 가져와 재전달,
   중복 제거와 예시 전달 단계 최대 4단계 제한, 기기 내 메시지 삭제

[안심 그룹의 기술적 한계 — 반드시 읽기]
- 자동 블루투스 BLE 또는 Wi-Fi Direct 메쉬 통신은 구현되어 있지 않습니다.
- 일반 웹사이트는 휴대전화 간 BLE 광고와 Wi-Fi Direct 직접 통신을 제어할 수 없습니다.
  이를 실제로 구현하려면 네이티브 Android/iOS 앱, 플랫폼 권한, BLE/GATT 또는
  Wi-Fi P2P 구현, 장치·배터리·보안 테스트가 필요합니다.
- 이 웹 버전은 QR/전달 코드/파일을 사람 사이에서 직접 교환하는 '수동 저장-전달'
  시제품입니다. 자동 전달, 수신 확인, 메시지 암호화, 신원 인증, 실시간 위치 추적 없음.
- 전달 코드에는 메시지가 평문으로 포함됩니다. 실제 이름·전화번호·상세 주소·실시간
  위치 등 민감한 개인정보를 넣지 마세요. 그룹 코드는 비밀키나 비밀번호가 아닙니다.
- 진짜 재난 상황에서 이 실습용 기능에 의존하지 마세요. 119/112 등 공식 긴급 연락 우선.

[오프라인 사용 범위]
- HTTPS 배포 또는 localhost에서 페이지를 처음 연 뒤 브라우저 서비스워커가
  설치·캐시되어야 하며, 브라우저 설정에 따라 오프라인 재접속이 안 될 수도 있습니다.
- 같은 기기에서 이미 열린 페이지는 오프라인 상태에서도 폼·목록 등을 계속 사용할 수 있습니다.
- 기기를 바꾸거나 브라우저 데이터를 지우면 저장 목록은 이동/삭제될 수 있습니다.
- 안심 그룹 메시지를 다른 기기로 전달하려면 QR을 직접 보여주거나 코드/파일을
  블루투스 근거리 공유 같은 외부 수단으로 사람이 전송해야 합니다.
- 카메라 QR 스캔은 지원하는 브라우저와 HTTPS 또는 localhost의 카메라 권한이 필요합니다.
  지원되지 않으면 코드 붙여넣기/전달 파일 가져오기를 이용하세요.
- 지도 배경, 실시간 API, 외부 지도 타일은 인터넷 연결 또는 원본 백엔드가 필요합니다.

[발표 시 시연 추천]
1) 비상용품 관리함: 생수 2병/목표 6병 입력 → 보충 필요 4병 → + 버튼으로 수량 수정 → 목록 TXT 저장
2) 안심 그룹: 브라우저 A에서 그룹 '우리반' 만들기 → '안전함' 안부 작성 → QR/코드 생성
   → 다른 브라우저 기기 B에서 같은 그룹 코드 입력 → 전달 코드 가져오기 → 중복 제외
   → 기기 B에서 다음 기기 C로 코드 재전달(단계 2/4 표시)
3) 홈 화면 아래의 문의·도움말과 기존 지도/강수량/대피시설/통계 화면을 보여주세요.

[프로젝트 보안·운영 주의]
- 모든 새 데이터는 해당 브라우저 로컬 저장소에만 저장됩니다. 서버가 없습니다.
- 신고서는 자동 접수되지 않으며 물품 매칭은 실제 지원을 연결하지 않습니다.
- 기존 weather.js의 공공 API 키는 클라이언트 코드에 남아 있으므로 공개 배포 전에
  노출 및 발급 범위를 점검하고 키를 서버로 이전해야 합니다.
